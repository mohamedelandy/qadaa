# Maestro flows

This directory contains behavioral end-to-end flows, reusable setup utilities, suites, and a separate LinkedIn showcase flow.

- `flows/` — individual deterministic behavior flows.
- `suites/` — smoke and regression compositions.
- `utils/` — reusable setup fragments.
- `../showcase.yaml` — paced product-story recording flow.

Run the inventory generator after changing flow headers or suite wiring:

```bash
npm run maestro:inventory
```
